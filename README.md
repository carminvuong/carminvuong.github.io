# Portfolio

Personal site made using Astro, deployed to GitHub Pages.


## Routes

| Route | Source |
|---|---|
| `/` | `src/pages/index.astro` — bio, featured project, experience, skills, education |
| `/projects/` | `src/pages/projects/index.astro` — every project |
| `/projects/<slug>/` | `src/pages/projects/[...slug].astro` |
| `/404` | `src/pages/404.astro` |


## Design notes

Vivid orange (`#FF5A00`) was deliberate. I love orange.

Typefaces: Bricolage Grotesque (display), Newsreader (body), IBM Plex Mono (data
and labels). 

Favicon made using [favicon.io](https://favicon.io/) .

Everything from Google Fonts.
